# AIM:
To develop the Hospital management System using Star UML tool.
# SRS (Procedure):
1. **Problem Identification** – Identify the need to manage hospital operations digitally.
2. **Requirement Gathering** – Collect requirements from doctors, staff, and patients.
3. **System Analysis** – Study the existing manual process and identify problems.
4. **System Design** – Design modules for patient registration, doctor scheduling, billing, and records.
5. **Functional Specification** – Define main functions like add patient, assign doctor, generate bills, and store reports.
6. **Non-Functional Specification** – Specify needs for security, speed, and data accuracy.
7. **Testing & Validation** – Test each module to ensure proper functioning and data handling.
8. **Documentation & Maintenance** – Prepare reports, user manuals, and update the system as needed.
